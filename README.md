##   نصب و اجرا 

1. کلون کردن برنامه :

```bash
git clone https://github.com/username/ToDoApp.git
cd ToDoApp
```
---

| متد    | مسیر        | توضیح               |
| ------ | ----------- | ------------------- |
| GET    | /tasks      | دریافت تمام تسک‌ها  |
| POST   | /tasks      | اضافه کردن تسک جدید |
| GET    | /tasks/\:id | دریافت یک تسک خاص   |
| PUT    | /tasks/\:id | ویرایش یک تسک       |
| DELETE | /tasks/\:id | حذف یک تسک          |
